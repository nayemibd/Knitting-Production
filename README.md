# Knitting Production

## All Company Knitting Production — SQL Query & Power BI Visualization

This project focuses on analyzing **knitting production data** from multiple companies using **SQL queries** and **Microsoft Power BI**.

The objective is to transform raw production data into meaningful information and interactive dashboards that can help management and production teams monitor performance and make data-driven decisions.

---

## 📌 Project Overview

The project includes:

- Production data collection and preparation
- SQL queries for data extraction and analysis
- Data cleaning and transformation
- Production performance analysis
- Power BI data modeling
- Interactive Power BI dashboards
- Production-related KPIs and visualizations
